# Lending Policy Assistant

Questions about Indian bank lending rules, answered only from 11 RBI Directions and 7 banks'
own policies, with page-level citations. Compare plain RAG, a hand-written ReAct agent and a
LangGraph agent, and see each agent's steps.

Code, evaluation and results: https://github.com/rc-mathew/agentic-lending-policy-rag

Free-tier demo: model calls are capped per visitor and per day. Not legal or financial advice.
